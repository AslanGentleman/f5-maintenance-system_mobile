# F-5 MIS - Maintenance Information System

Sistema Web interativo desenvolvido para centralizar, organizar e facilitar o acesso a documentações técnicas e módulos de manutenção aeronáutica.

---

## 🚀 Funcionalidades

- **Navegação por Módulos:** Separação intuitiva entre *Job Guides*, *Catálogo de Peças (IPB)* e *Troubleshooting*.
- **Interface Tática/Militar:** Design dark theme otimizado para visualização técnica e rápida leitura em campo.
- **Layout Totalmente Responsivo:** Adaptado com CSS Grid e Flexbox para desktops, tablets e dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica e acessível)
- **CSS3** (CSS Grid, Flexbox, Media Queries e variáveis)
